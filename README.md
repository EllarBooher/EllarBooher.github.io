# EllarBooher.github.io

This website was built with React and Vite, and written in Typescript. It hosts my portfolio, with links to other projects alongside WebGPU demos that work in compatible browsers.

A large portion of the content lives in a private NPM package hosted at <https://github.com/EllarBooher/WebGPU-Samples>. `WebGPU-Samples` contains small bespoke samples of WebGPU in Javascript alongside the React components to embed them and their READMEs.
